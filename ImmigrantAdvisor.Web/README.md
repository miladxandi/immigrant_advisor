# 🌍 Immigrant Advisor - مشاور مهاجرت هوشمند

اپلیکیشن مشاوره مهاجرت هوشمند بر پایه .NET 10 و Blazor Web App

## ✨ ویژگی‌ها

- فرم جامع ورود اطلاعات شامل:
  - اطلاعات شخصی (سن، جنسیت، وضعیت تأهل، فرزندان)
  - تحصیلات و زبان (مقطع تحصیلی، سطح زبان‌های مختلف)
  - شغل و تخصص (شغل فعلی، سابقه کار، درآمد)
  - وضعیت مالی (دارایی‌ها، پس‌انداز، سرمایه‌گذاری)
  - سلامت جسمی و روانی (سلامت عمومی، تحمل استرس، سازگاری)
  - اجتماعی و فرهنگی (ترجیحات فرهنگی، مذهبی، جامعه)
  - اهداف مهاجرت (اهداف اصلی، زمان‌بندی، تابعیت)
  - ترجیحات جغرافیایی (آب‌وهوا، فاصله از ایران)

- دیتابیس ۱۰ کشور با اطلاعات کامل:
  - کانادا 🇨🇦
  - آلمان 🇩🇪
  - استرالیا 🇦🇺
  - ترکیه 🇹🇷
  - امارات 🇦🇪
  - سوئد 🇸🇪
  - نیوزیلند 🇳🇿
  - هلند 🇳🇱
  - پرتغال 🇵🇹
  - انگلستان 🇬🇧
  - آمریکا 🇺🇸

- موتور پیشنهاد هوشمند بر اساس امتیازدهی
- نمایش ویزای مناسب برای هر کشور
- نقاط قوت، چالش‌ها و توصیه‌ها
- مراحل اقدام گام به گام
- رابط کاربری کاملاً فارسی با فونت وزیرمتن و RTL

## 🚀 راه‌اندازی

### پیش‌نیازها

- .NET 10 SDK یا بالاتر

### نصب و اجرا

```bash
# کلون کردن ریپو
git clone https://github.com/miladxandi/immigrant_advisor.git
cd immigrant_advisor

# اجرا
dotnet run
```

اپلیکیشن در `http://localhost:5000` در دسترس خواهد بود.

## 🛠️ ساختار پروژه

```
ImmigrantAdvisor.Web/
├── Components/
│   ├── Pages/
│   │   ├── Home.razor          # فرم ورود اطلاعات
│   │   └── Results.razor       # صفحه نتایج
│   ├── Layout/
│   │   └── MainLayout.razor    # لایه‌بندی اصلی
│   └── App.razor               # کامپوننت اصلی
├── Models/
│   ├── UserFactors.cs          # مدل‌های ورودی کاربر
│   └── Country.cs              # مدل‌های کشور و ویزا
├── Services/
│   ├── ImmigrationAdvisorService.cs  # موتور پیشنهاد
│   └── AppStateService.cs      # مدیریت state
├── Data/
│   └── CountryData.cs          # داده‌های کشورها
└── wwwroot/
    └── app.css                 # استایل‌های سفارشی
```
